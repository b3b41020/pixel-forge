# Pixel Forge — AI 图像工坊

**🌐 选择语言 / Choose language: [中文](README_zh.md) | [English](README.md)**

---

一个基于 [Pollinations](https://pollinations.ai) 构建的 AI 图像生成工坊。输入提示词，选择模型和尺寸，一键生成 —— 由 Pollinations 图像 API 驱动，支持一键钱包授权。

## 功能特点

- **文生图**：支持 6 种模型 —— Flux、Dreamshaper、Klein、GPT Image 2、Zimage、Nanobanana
- **尺寸选择**：1024×1024、1024×768、768×1024、512×512
- **一键登录**：通过 Pollinations 账户授权登录，开箱即用
- **本地历史**：生成记录自动保存在本地浏览器，支持下载、复制链接、分享
