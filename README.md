# Pixel Forge — AI Image Studio

**🌐 Choose language / 选择语言: [English](README.md) | [中文](README_zh.md)**

---

An AI image generation studio built on [Pollinations](https://pollinations.ai). Enter a prompt, pick a model and size, and generate — powered by the Pollinations image API with one-click wallet authorization.

## Features

- Prompt-to-image generation with 6 models: Flux, Dreamshaper, Klein, GPT Image 2, Zimage, Nanobanana
- Sizes: 1024×1024, 1024×768, 768×1024, 512×512
- One-click login via Pollinations account authorization
- Local generation history, download, copy URL, share
